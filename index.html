INTERACTIVE GUIDE
মনে রেখো: সংখ্যার মান 25, লেখার মান 'Rahim', তারিখ '2026-11-05'। VARCHAR(5)-এ সর্বোচ্চ ৫টি অক্ষর, আর DECIMAL(5,2)-এ মোট ৫টি অঙ্কের মধ্যে দশমিকের পরে সর্বোচ্চ ২টি অঙ্ক রাখা যায়।

💻 SQL Editor-এও চালিয়ে দেখো কোড দেখো

নিচের SQL কোড Run করলে সত্যিই টেবিল তৈরি হবে এবং নির্বাচিত value ঢুকবে—অথবা ভুল হলে Error দেখাবে।

CREATE TABLE TypePractice (
  id INT PRIMARY KEY,
  sample_value VARCHAR(5)
);
INSERT INTO TypePractice VALUES (1, 'Rafi');

Editor-এ পাঠালে শুধু Query বসবে। Run Query চাপলে Database Explorer-এ ফলাফল দেখাবে। একই পরীক্ষার জন্য পুরোনো TypePractice টেবিল মুছে নতুনটি তৈরি হবে।

🔎 এটি শেখার জন্য তুলনামূলক কঠোর (strict) সিমুলেটর। বাস্তব MySQL কিছু ক্ষেত্রে value স্বয়ংক্রিয়ভাবে রূপান্তর বা সংক্ষিপ্ত করতে পারে; এখানে তা দেখানো হয় না। BOOLEAN, CHAR এবং TIME-এর কিছু বাস্তব MySQL আচরণও সরল করা হয়েছে।

📚 শেখার ৬টি ধাপ

1
CREATE — নতুন টেবিল ও কলাম তৈরি
2
INSERT — টেবিলে নতুন রেকর্ড যোগ
3
UPDATE — পুরোনো রেকর্ডের মান বদলানো
4
ALTER — টেবিলের গঠন বদলানো
5
DELETE — টেবিল রেখে রেকর্ড মুছে ফেলা
6
DROP — সম্পূর্ণ টেবিল মুছে ফেলা
